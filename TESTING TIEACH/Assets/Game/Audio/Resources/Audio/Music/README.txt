Put your soundtrack mp3/wav/ogg files in this folder.

Examples:
  01 Under Construction.mp3
  02 Field Trip.mp3
  03 On the Road.mp3
  04 Are We There Yet.mp3
  05 Along for the Ride.mp3

Tips:
- Drag files into this folder in Unity's Project window (not only File Explorer).
- If you move/rename/delete a file outside Unity, delete its matching .meta too.
- MusicManager plays every AudioClip in this folder as a playlist.
