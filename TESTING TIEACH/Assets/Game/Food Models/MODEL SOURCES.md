# Current food model collection

This folder is now the game-facing source for food and ingredient models used by recipe data, station displays, worker-held previews, and food UI previews.

Some assets retain links to imported source meshes and materials. Game code preserves each prefab's authored world scale, so adjust the root scale on the prefab in this folder to change its size everywhere it appears.
